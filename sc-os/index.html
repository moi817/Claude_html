Mes opportunités

Synchronisation entre appareils

Tes données sont stockées dans un Gist GitHub secret (fichier sc-dashboard.json) de ton compte. Sur chaque appareil, il suffit de coller le même token : le Gist est retrouvé automatiquement.

Créer un token avec le seul droit « gist » ↗
Le token reste dans ce navigateur uniquement ; il n'est jamais envoyé ailleurs que sur api.github.com. Ne lui donne aucun autre droit.

Données locales

Une copie de sécurité de cet appareil est gardée automatiquement avant tout écrasement par le cloud ou un import.

Sources de données

FleetYards (modèles, images, hangars publics) · Star Citizen Wiki API (Comm-Link) · UEX Corp (prix de vente) · Gist GitHub (synchronisation, optionnelle).

Notifications téléphone (ntfy)

Installe l'app ntfy (Android / iOS, gratuite) et abonne-toi au sujet ci-dessous. À chaque raffinage lancé, l'alerte est programmée sur le serveur ntfy : elle arrive à l'heure dite même PC éteint ou page fermée (3 jours d'avance maximum).

Ouvrir le sujet ↗

Le nom du sujet sert de mot de passe : quiconque le connaît peut lire tes alertes. Garde-le privé (il est synchronisé avec tes données).

Application

Exports CSV

Séparateur « ; », encodage UTF-8 : s'ouvre directement dans Excel ou LibreOffice en français.

Alertes 24 h/24 (robot GitHub)

Un petit robot gratuit consulte les prix UEX et le Comm-Link RSI environ toutes les 15 minutes et t'envoie une notification ntfy, même application fermée et PC éteint. Il lit tes réglages dans ton Gist de synchronisation (les mêmes que ci-dessus).
