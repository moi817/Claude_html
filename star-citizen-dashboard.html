Synchronisation entre appareils

Tes données sont stockées dans un Gist GitHub secret (fichier sc-dashboard.json) de ton compte. Sur chaque appareil, il suffit de coller le même token : le Gist est retrouvé automatiquement.

Créer un token avec le seul droit « gist » ↗
Le token reste dans ce navigateur uniquement ; il n'est jamais envoyé ailleurs que sur api.github.com. Ne lui donne aucun autre droit.
